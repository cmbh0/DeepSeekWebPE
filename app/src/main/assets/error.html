启动提示

命令需要在 Termux 中执行。

安装完成后，运行 dsh web 保持服务在前台运行。不要关闭 Termux 的服务进程。

Termux 命令 
#!/bin/bash

# 设置国内镜像源
npm config set registry https://registry.npmmirror.com

# 方法1：直接用镜像下载（推荐）
npm i -g https://registry.npmmirror.com/dsh-termux/-/dsh-termux-1.0.0.tgz

# 如果上面不行，试试方法2：用ghproxy代理GitHub
# npm i -g https://ghproxy.com/https://github.com/sunflower2333/dsh-termux/releases/latest/download/dsh-termux.tgz

# 检查版本
dsh --version

# 启动Web UI
dsh web
执行完成后返回此页面，点击悬浮菜单里的重试图标。服务地址必须保持为 127.0.0.1:3080。
